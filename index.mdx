Hero is a map-based geography and history quiz built as a static site with Firebase and EdgeOne serverless functions. Students identify and locate places on an interactive map, get AI-powered help from Clio (a Gemini-backed study guide), connect their Canvas LMS for grades and assignments, and track their weak spots across sessions. You deploy Hero as your own site — it is self-hosted on EdgeOne Pages with your own Firebase project.

## Deployment overview

<Steps>
  <Step title="Fork and clone">
    Fork `crwcln/heroapp` on GitHub and clone it to your machine. Run `npm run setup:git-hooks` once to enable the version-prefixed commit workflow.
  </Step>
  <Step title="Configure the site">
    Edit `js/00-site-config.js` to set your site name, ID, and feature flags. Edit `js/02-firebase-config.js` with your Firebase project credentials.
  </Step>
  <Step title="Set environment variables">
    Add all required secrets — `ADMIN_PASSWORD`, Firebase service-account keys, `GEMINI_API_KEY`, etc. — in your EdgeOne Pages project settings.
  </Step>
  <Step title="Deploy to EdgeOne">
    Connect your GitHub repo to EdgeOne Pages. Each push triggers a build that cache-busts assets and deploys the latest version automatically.
  </Step>
</Steps>

<Note>
  Hero's Firebase web config (`js/02-firebase-config.js`) is intentionally public — it is browser-safe configuration, not a service-account credential. Keep service-account private keys, admin passwords, and API keys only in EdgeOne environment variables.
</Note>
